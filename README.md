# ポッチモザイク工房

画像を読み込むと、色を絞ってざらつきをならしたうえで、レゴの「ポッチ正面（8×8mm）」「タイル」「横積み（8×3.2mm）」「縦積み（3.2×8mm）」を同じ色の部分ごとに自動で使い分けたモザイクに変換するツールです。AIは使わず、ブラウザの中の計算だけで動きます。

**使ってみる → https://becanmezon.github.io/pocchi-mosaic/**

## しくみ

16mm角のブロックには、ポッチ2×2・プレート横5段・プレート縦5列のどれもぴったり収まります（8mm×2 = 3.2mm×5 = 16mm）。
ブロックごとに3つの積み方で元画像との色のズレを計算し、平らな所はポッチ正面、横線の多い所は横積み、縦線の多い所は縦積みを選びます。

## 機能

- 画像の読み込み（ファイル選択・ドラッグ＆ドロップ・貼り付け）
- 横幅（ポッチ数）、ブロック幅、使う積み方、細部の拾いやすさの調整
- 色数の上限（その絵に合うLEGO実在色を自動で選択。38色から候補の絞り込み可）
- ノイズ除去（輪郭を残してかすれやざらつきをならすKuwaharaフィルタ）とゴミ取り
- 積み方を「同じ色の部分ごと」または「ブロックごと」に判定、広い単色面はタイルに
- マス目の線と下絵を重ねて、1マスずつ色を塗る／スポイト／積み方の切替／元に戻す
- 色ごとのパーツ表（同じ色が続く所は1×2〜1×8プレートにまとめて計算）
- 完成イメージのPNG（右クリックでコピー・保存）
- LDraw（.ldr）ファイルの書き出し：BrickLink Studio（Stud.io）やLeoCADで開けます

ブラウザだけで動く1ファイルのHTMLです。画像はどこにも送信されません。
