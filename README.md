# ポッチモザイク工房

画像を読み込むと、色を絞ってざらつきをならしたうえで、レゴの「ポッチ正面（8×8mm）」「タイル」「横積み（8×3.2mm）」「縦積み（3.2×8mm）」を同じ色の部分ごとに自動で使い分けたモザイクに変換するツールです。AIは使わず、ブラウザの中の計算だけで動きます。

**使ってみる → https://becanmezon.github.io/pocchi-mosaic/**

## しくみ

16mm角のブロックには、ポッチ2×2・プレート横5段・プレート縦5列のどれもぴったり収まります（8mm×2 = 3.2mm×5 = 16mm）。
ブロックごとに3つの積み方で元画像との色のズレを計算し、平らな所はポッチ正面、横線の多い所は横積み、縦線の多い所は縦積みを選びます。

## 機能

- 画像の読み込み（ファイル選択・ドラッグ＆ドロップ・貼り付け）
- 横幅（ポッチ数）、ブロック幅、使う積み方、細部の拾いやすさの調整
- 色数の上限（その絵に合うLEGO実在色を自動で選択。38色から候補の絞り込み可）
- ノイズ除去（輪郭を残してかすれやざらつきをならすKuwaharaフィルタ）とゴミ取り
- 積み方を「同じ色の部分ごと」または「ブロックごと」に判定、広い単色面はタイルに
- マス目の線と下絵を重ねて、1マスずつ色を塗る／スポイト／積み方の切替／元に戻す
- 色ごとのパーツ表（同じ色が続く所は1×2〜1×8プレートにまとめて計算）
- 完成イメージのPNG（右クリックでコピー・保存）
- 設計データ（.json）の保存・読み込み：元画像・各マスの色・積み方をまとめて保存し、続きから手直しできます
- 立体（レリーフ）：設計データに「立体の層」があると、3Dプレビュー（回転・拡大・影）、部位ごとの高さ調整、奥行き込みのLDRとパーツ表（見えない裏打ちも別に集計）を出します
- 見本：星月夜（立体）。糸杉・村・教会・丘・月と星を部位ごとに手前へ出した例
- 見本：雷神（Claude設計）。部位ごとに積み方と色の役割を決め、目は1マスずつ設計したモザイク
- LDraw（.ldr）ファイルの書き出し：BrickLink Studio（Stud.io）やLeoCADで開けます

ブラウザだけで動く1ファイルのHTMLです。画像はどこにも送信されません。

LEGO® はレゴグループの商標です。このツールはレゴグループとは関係ありません。

## ルーバーレンチキュラー

**使ってみる → https://becanmezon.github.io/pocchi-mosaic/lenticular.html**

縦積みのプレートを壁から突き出させた「ひれ」で、見る角度によって3枚の絵が入れ替わる作品を設計します。

- ひれ1枚＝プレート（左面＝絵A）＋タイル（右面＝絵B）、厚さ6.4mm
- ひれの間から見える壁（1×1タイル）＝絵C
- 左から見るとA、正面からC、右からB。見る角度のスライダーと「ゆらして見る」で見え方を確認
- ひれの間隔（16mm／24mm）と奥行き（16／24／32mm）を選択
- パーツ表とLDR（Stud.io／LeoCAD用）を出力

## スロープレンチキュラー

**使ってみる → https://becanmezon.github.io/pocchi-mosaic/slope-lenticular.html**

1×1のスロープ（Slope 30 1×1×2/3、部品番号 54200）を左向き・右向きで1列ずつ交互に並べ、左から見ると絵A、右から見ると絵Bに切り替わる定番のレンチキュラーを設計します。角度スライダーでの見え方確認、パーツ表、LDR出力に対応しています。
